💧 Consumo de Água

Sistema desenvolvido em Python para classificar o perfil de consumo de água de diferentes tipos de imóveis e exibir mensagens educativas de acordo com o consumo informado.

🎯 Objetivo

O projeto foi desenvolvido como atividade acadêmica com o objetivo de praticar algoritmos, estruturas condicionais e programação estruturada em Python.

O programa solicita:

🏠 Tipo de imóvel: casa, apartamento ou comercial
💧 Consumo mensal de água em metros cúbicos (m³)

Após receber os dados, o sistema classifica o consumo de acordo com as regras estabelecidas.

📋 Regras do sistema
Tipo de imóvel	Consumo	Resultado
Comercial	Qualquer valor	💼 Tarifa comercial aplicada
Apartamento	Menor que 10 m³	🌱 Consumo econômico
Casa ou apartamento	Até 25 m³	💧 Consumo moderado
Demais situações	Acima do limite	⚠️ Consumo excessivo
