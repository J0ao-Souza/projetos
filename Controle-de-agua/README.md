# 💧 Controle de Níveis de Água

Projeto desenvolvido em Python para simular o nível de água de um reservatório e exibir mensagens de alerta coloridas no terminal, utilizando a biblioteca Colorama.

## 🎯 Objetivo

O objetivo do projeto é praticar conceitos fundamentais da programação em Python, como listas, funções, estruturas condicionais e utilização de bibliotecas externas.

## ⚙️ Funcionalidades

- Armazenamento das mensagens dos níveis de água em uma lista.
- Identificação da situação atual do reservatório.
- Seleção de cores de acordo com o nível da água.
- Exibição de mensagens coloridas no terminal.
- Restauração do estilo do terminal após a mensagem.

## 🚦 Níveis do reservatório

| Nível | Situação | Cor |
|:---:|---|---|
| 1 | Muito baixo (crítico) | 🔴 Vermelho |
| 2 | Baixo | 🟡 Amarelo |
| 3 | Médio | 🟢 Verde |
| 4 | Alto | 🩵 Ciano |
| 5 | Muito alto (alerta) | 🔵 Azul |

## 🛠️ Tecnologias utilizadas

- **Python** — linguagem de programação.
- **Colorama** — biblioteca utilizada para exibir cores no terminal.

## ▶️ Como executar o projeto

**1.** Clone este repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

**2.** Entre na pasta do projeto:

```bash
cd Controle-de-agua
```

**3.** Instale a biblioteca necessária:

```bash
pip install colorama
```

**4.** Execute o programa:

```bash
python app.py
```
