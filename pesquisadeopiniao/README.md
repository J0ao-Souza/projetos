📊 Pesquisa de Opinião

Projeto desenvolvido em Python para realizar uma pesquisa de opinião sobre o atendimento prestado por uma empresa.

O programa coleta informações de 50 entrevistados, como nome, idade e opinião sobre o atendimento, e ao final apresenta a quantidade de respostas para cada categoria.

🎯 Objetivo

Desenvolver um programa utilizando estruturas de repetição e estruturas de decisão para coletar e contabilizar opiniões de clientes sobre o atendimento.

🛠️ Tecnologias utilizadas
Python
for
while
if / elif
input()
print()
Variáveis e contadores
⚙️ Funcionamento

Para cada um dos 50 entrevistados, o programa solicita:

Nome
Idade
Opinião sobre o atendimento

As opções de opinião são:

Excelente
Bom
Ruim

O programa também possui uma validação que impede a continuação enquanto uma opção diferente de 1, 2 ou 3 for informada.

Ao final da pesquisa, são exibidas as quantidades de respostas:

Excelente
Bom
Ruim
📋 Exemplo de resultado
Resultados da pesquisa:
Excelente: 20
Bom: 18
Ruim: 12

Os números acima são apenas um exemplo de execução.

▶️ Como executar
Tenha o Python instalado no computador.
Baixe ou clone este repositório.
Abra a pasta do projeto no VS Code ou outro editor.
Execute o arquivo:
pesquisa_opiniao.py
Responda às perguntas apresentadas no terminal.
🧪 Testes

Foram realizados testes durante o desenvolvimento para verificar:

Entrada de nome e idade;
Seleção das opções de opinião;
Bloqueio de opções inválidas;
Contagem das respostas;
Exibição dos resultados ao final da pesquisa.
